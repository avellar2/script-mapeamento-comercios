# Arquitetura de Mensagens Rio Premium (APROVADA)

## Estrutura da mensagem ideal

```
[Saudação] [Vi/Encontrei] [artigo] [referencia] [NOME DO COMERCIO] no Google.
[Dor indireta: notei que... poderia ficar mais...]
[Consequencia suave: quando [cliente/paciente] precisa... pode acabar...]
[Se apresentar: Eu trabalho criando páginas para...]
[CTA suave: Posso te mandar uma prévia visual de como ficaria?]
```

## Regras (APROVADAS PELO USUÁRIO)

1. **Citar NOME do comércio** na primeira frase — SEMPRE
2. **Dor INDIRETA**: "pode acabar agendando em outro lugar" — NUNCA "você está perdendo cliente"
3. **Se apresentar**: "Eu trabalho criando páginas para..." — SEMPRE
4. **Sem asteriscos/negrito** — WhatsApp não renderiza
5. **Acentuação OBRIGATÓRIA** — o usuário rejeitou mensagens sem acentos
6. **CTA suave** — "Posso te mandar uma prévia visual?"
7. **3 variações por tipo** — nunca repetir a mesma mensagem

## 6 tipos de mensagem

### Tipo 1: Agendamento (salão, barbearia, clínica estética, dentista)
"Olá, tudo bem? Vi [artigo] [referencia] [NOME] no Google. Notei que as informações de serviços e agendamento poderiam ficar mais fáceis de encontrar em uma página simples. Quando a cliente precisa procurar muito, ela pode acabar agendando em outro lugar. Eu trabalho criando páginas para [referencia]. Posso te mandar uma prévia visual de como ficaria?"
